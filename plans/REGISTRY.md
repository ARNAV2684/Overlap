## Hot shared files

Several layers depend on these. Change them only in small, dedicated commits or PRs, after telling the people listed.

| File or folder | Why it is shared | Tell before changing |
|---|---|---|
| `CONTRACTS.md` | Every message between layers | The producer and consumer owners of the section you change |
| `fixtures/` | Examples every layer builds against | The owners of the messages the fixture shows |
| `README.md`, `CONTRIBUTING.md` | Everyone reads them | Arnav |
| `.github/` | PR template, future CI | Arnav |
| `.claude/skills/` | The team's planning workflow | Arnav, Pranav |
| `plans/REGISTRY.md` | Ownership | Arnav (only Arnav edits owners) |
| `azure.yaml`, `infra/main.bicep` | Every Azure resource | Arnav, Pranav |
| `web/src/lib/contracts.ts` (once it exists) | Web copy of the shared contracts | Vedant, and the owner of the contract changed |
| Lockfiles and other generated files (once they exist) | Regenerated by tools | Never hand-merge; regenerate after merging `main` |
