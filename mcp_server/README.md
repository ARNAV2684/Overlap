# MCP server

Exposes match stats as MCP tools for the tactical analyst (and any MCP client), for example `get_match_state`,
`compare_periods`, `get_pressing_window`, `get_player_context`, `get_pass_network` and `get_season_milestones`.

The folder is called `mcp_server` (not `mcp`) so it can never shadow the official `mcp` Python SDK.
